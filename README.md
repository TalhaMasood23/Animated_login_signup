# 🔐 Free Login & Signup Page (HTML, CSS, JavaScript)

Welcome! 👋  
This is a **free and fully responsive Login and Signup page** built with **HTML, CSS, and vanilla JavaScript**. Whether you're building a portfolio, a personal website, or a new web app, this simple UI is ready to plug in and customize.

---

## 📄 Project Description

This project contains two core components:
- **Login Page**: For existing users to sign in
- **Signup Page**: For new users to register an account

The interface is clean, mobile-friendly, and lightweight — perfect for quick integration or as a starter template.

---

## ✨ Features

- 🔐 Login and Signup form layouts
- 🎨 Clean, modern design using CSS Flexbox
- 📱 Fully responsive (mobile, tablet, desktop)
- 🧠 Toggle between forms using JavaScript
- 🧩 Easy to customize and extend
